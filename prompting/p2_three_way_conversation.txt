`self` is a **convention** (not a keyword!) used to represent the **instance of the class** (i.e., the object created from the class). When you create an object (e.g., `customer1 = Customer()`), `self` refers to that specific object (`customer1` in this case).

Think of `self` like a unique ID badge for an employee in a company:
- Every employee (instance) has their own badge (`self`) with their name, role, and access to their personal data (instance variables/methods).
- The badge (`self`) lets them interact with company systems (class methods) while keeping their data separate from others.

---

### **2. Why Do We Need `self`?**
In a class, methods need a way to:
- Access or modify **instance-specific data** (e.g., a customer's name or balance).
- Call other methods **belonging to the same instance**.

Without `self`, Python wouldn’t know *which instance’s data* to use.

#### **Example: Banking System**
```python
class BankAccount:

        self.account_holder = account_holder  # Instance variable

        print(f"Deposited ${amount}. New balance: ${self.balance}")

```
Here, `self` ensures `account1` and `account2` keep their balances separate.
